1. Install the lab components
Step 1 — Update Kali
sudo apt update

Step 2 — Install Docker
sudo apt install -y docker.io
sudo systemctl enable --now docker

Verify:

sudo systemctl status docker


Active: active (running)

Step 3 — Download Juice Shop
sudo docker pull bkimminich/juice-shop

Start it locally:

sudo docker run --rm --name juice-shop \
  -p 127.0.0.1:3000:3000 \
  bkimminich/juice-shop

The official Juice Shop documentation confirms this Docker deployment approach.

Leave that terminal running.

Open Firefox:

http://127.0.0.1:3000

You should see Juice Shop.
